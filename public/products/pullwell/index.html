Pullwell

Downloads that finish.

A download manager for Windows that resumes after crashes and dropped connections, checks every finished file, and sends no telemetry.

Early releasesv0.10.0Windows 10 and 11
Download for WindowsSource on GitHub

The problem

Big downloads fail in boring ways.

The connection drops at 94%. The PC restarts overnight. The file arrives a few bytes short and nothing tells you.

Pullwell picks up where it stopped after a crash, a restart or a lost connection. It never calls a file finished unless the size is right, and the checksum too when one is known.

What it does

  • 01

    Several connections per file

    Files are fetched in parts over several connections at once, which is also what lets NetMerge spread one download across lines.

  • 02

    Queues with their own hours

    A scheduler, speed limits overall or per download, categories, mirrors and numbered series.

  • 03

    More than plain files

    FTP, HLS and DASH web video, and BitTorrent.

  • 04

    Its own browser extension

    For Chrome, Edge, Brave and Firefox. Large downloads go to Pullwell; when it is not running, the browser downloads as usual.

  • 05

    One file, no installer

    No administrator prompt. It updates itself, checks each update against its fingerprint, and can go back to the previous version.

  • 06

    Nothing phones home

    No telemetry. Settings and the download list sit in a folder next to the program.

Honest limits

  • "Pullwell" is a working name and may change after a trademark check.
  • These are the first public versions. They are in daily use, and rough edges are likely.
  • The program is not code-signed yet, so Windows asks you to confirm the first run.
