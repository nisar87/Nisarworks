NetMerge for Android

Wi-Fi and mobile data, at the same time.

An Android app that sends your phone's traffic over Wi-Fi and mobile data together, with more of it on whichever is faster.

Testingv0.1.0Android 10 and newer
Get a test buildSource on GitHub

The problem

Your phone has two ways online and uses one.

When Wi-Fi is connected, Android leaves mobile data idle, even when the Wi-Fi is slow or about to drop.

NetMerge for Android runs a VPN on the phone itself that sees every app's traffic. Each new connection goes out over Wi-Fi or mobile data, and the faster network gets more of them. Nothing is sent through a server of mine.

What it can and cannot do

Apps that open many connections

  • Wi-Fibusy
  • Mobilebusy

Downloads, app stores, browsers and streaming open many connections. Each new one is sent over Wi-Fi or mobile data, with more going to the faster network.

One single connection

  • Wi-Fibusy
  • Mobileidle

A single connection stays on one network. NetMerge does not join two networks into one faster pipe, so it does not double your speed.

What it does

  • 01

    Learns each network

    It works out how fast Wi-Fi and mobile data are from the traffic they carry, and shares new connections to match.

  • 02

    Survives a dropout

    When a network leaves, its connections are closed at once so apps reconnect on the one that still works. In tests a download stalled for under 3 seconds.

  • 03

    Mobile data only when it helps

    An optional setting lets mobile data go after a quiet minute and brings it back for big downloads.

  • 04

    A daily limit

    Set how much mobile data merging may use each day.

  • 05

    A built-in speed test

    It tests Wi-Fi alone, mobile data alone, then both together, so you can see the merged speed for yourself.

  • 06

    Ads and trackers blocked

    Optional block lists stop ads, trackers and harmful sites for every app while NetMerge is on.

  • 07

    A battery guard, in testing

    Merging can pause when the battery falls to a level you choose. Apps keep using the phone's normal network.

  • 08

    Leave apps out

    Pick apps that should not go through the merge.

What it asks of your phone

  • 01

    It runs as a VPN

    That is how one app can see and steer every other app's traffic. The VPN lives on the phone itself. Your traffic is not sent through a server of mine.

  • 02

    One VPN at a time

    Android allows a single VPN to be active, so NetMerge cannot run together with another VPN app.

  • 03

    Permissions

    Network access and network state, a notification while merging is on, and the VPN permission you approve on first start.

  • 04

    What it does not ask for

    No location, no contacts, no files, no account.

Honest limits

  • It is in testing. The builds are made for trying on a real phone. They are not a release and not meant for daily use yet.
  • Tested on one phone, a Galaxy S26 Ultra. Other phones and carriers may behave differently.
  • Not yet tested on a real phone: a Wi-Fi network without internet, the always-on VPN after a restart, and overnight battery limits.
  • Merging uses mobile data, and keeping mobile data awake costs some battery. In the measured downloads, mobile data carried about a quarter of each file.
  • Test builds are signed with a public test key. A release will use a private one.
