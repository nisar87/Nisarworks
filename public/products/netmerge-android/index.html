NetMerge for Android

Wi-Fi and mobile data, at the same time.

An Android app that sends your phone's traffic over Wi-Fi and mobile data together, with more of it on whichever is faster.

The problem

Your phone has two ways online and uses one.

When Wi-Fi is connected, Android leaves mobile data idle, even when the Wi-Fi is slow or about to drop.

NetMerge for Android runs a VPN on the phone itself that sees every app's traffic. Each new connection goes out over Wi-Fi or mobile data, and the faster network gets more of them. Nothing is sent through a server of mine.

What I measured

  • 61.7MbpsMerging off, Wi-Fi alone
  • 85.2MbpsMerging on, Wi-Fi and mobile data
  • +38%Average gain

Three rounds on a Galaxy S26 Ultra with home Wi-Fi and 4G: one 140 MB file over 16 connections. Single runs vary, and your networks will differ.

What it does

  • 01

    Learns each network

    It works out how fast Wi-Fi and mobile data are from the traffic they carry, and shares new connections to match.

  • 02

    Survives a dropout

    When a network leaves, its connections are closed at once so apps reconnect on the one that still works. In tests a download stalled for under 3 seconds.

  • 03

    Mobile data only when it helps

    An optional setting lets mobile data go after a quiet minute and brings it back for big downloads.

  • 04

    A daily limit

    Set how much mobile data merging may use each day.

  • 05

    Live speed per network

    The main screen shows what Wi-Fi and mobile data are each carrying.

  • 06

    A quick settings tile

    Switch merging on and off from the notification shade.

Honest limits

  • These are test builds, made for trying on a real phone. They are not a release and not meant for daily use yet.
  • One single connection still uses one network. The gain comes from apps that open many connections, such as downloads, app stores, browsers and streaming.
  • Merging uses mobile data. In the measured downloads, mobile data carried about a quarter of each file.
  • Test builds are signed with a public test key. A release will use a private one.
